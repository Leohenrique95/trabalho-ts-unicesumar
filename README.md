4. COMO EXECUTAR O PROJETO
--------------------------------------------------------------------------------
1. Para atualizar a compilação (Gerar pasta /dist):
   > npx tsc

2. Para executar o menu principal:
   > node dist/menu.js

3. Para gerar o executável (.exe) na pasta /bin:
   > npm run make-exe

4. Para rodar diretamente:
   - Basta abrir o ficheiro **bin/TrabalhoTs.exe**

--------------------------------------------------------------------------------
5. REQUISITOS E INSTALAÇÃO DO AMBIENTE
--------------------------------------------------------------------------------
Para rodar ou editar este projeto, siga os passos abaixo:

1. **Instalação do Node.js:**
   - Baixe e instale a versão **LTS** (Recomendada) em: https://nodejs.org/
   - O Node.js é necessário para executar o JavaScript e gerenciar pacotes (npm).

2. **Configuração do VS Code:**
   - Abra a pasta do projeto no VS Code.
   - Instale estas extensões para facilitar o desenvolvimento:
     * **TypeScript Nightly**: Melhora o suporte e inteligência da linguagem.
     * **ESLint**: Ajuda a identificar erros de sintaxe em tempo real.
     * **Prettier**: Formata seu código automaticamente ao salvar.

3. **Instalação das Dependências:**
   - No terminal do VS Code, execute o comando abaixo para instalar o compilador e o empacotador:
     > npm install

4. **Gerando o Executável:**
   - Caso deseje gerar o arquivo .exe novamente, utilize:
     > npx tsc
     > npm run make-exe
